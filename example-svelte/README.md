# Svelte Chat Example App

The chat app from [`example/`](../example/) built with Svelte 5 and the
`@convex-dev/persistent-text-streaming/svelte` bindings. It shares the Convex
backend in `example/convex` and the dependencies in the root `package.json`.

## Running the app

From the repository root:

```bash
npm install
npm run dev # in one terminal
npm run dev:svelte # in another terminal
```

Set `OPENAI_API_KEY` as described in the
[React example's README](../example/README.md#establishing-your-openai_api_key).
